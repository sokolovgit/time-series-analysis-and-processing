## Команди

Усе запускається через `just` із каталогу `lab-N/project`. Не викликати `pip`
і не запускати `python` напряму — залежностями керує `uv`.

```
just            список рецептів
just sync       встановити залежності (uv sync)
just run        запустити лабу (uv run python -m labN)
just lint       ruff check
just fmt        ruff format + ruff check --fix
just check      перевірка форматування + лінт, нічого не змінює
just clean      прибрати output/ та __pycache__
```

## Zed

Проєктні налаштування лежать у `.zed/` і комітяться:

- `settings.json` — Python на ruff + pyright, формат при збереженні, організація імпортів,
  з індексації прибрані `.venv`, `__pycache__`, `.ruff_cache`. Для підсвітки `justfile`
  треба доставити розширення Just.
- `tasks.json` — рецепти `lab: run / check / fmt / sync / clean` (`cmd-shift-p` → `task: spawn`).
  Вони запускають `just` з каталогу відкритого файлу, а `just` сам знаходить
  `lab-N/project/justfile` вище по дереву — тобто працюють у будь-якій лабі без переналаштування.

Інтерпретатор для pyright береться з `[tool.pyright]` у `lab-N/project/pyproject.toml`
(`venvPath = "."`, `venv = ".venv"`), тому кожна лаба бачить своє оточення.

## Нова лабораторна

`lab-1/project` — шаблон. Для `lab-N`:

1. `cp -R lab-1/project lab-N/project` (без `.venv`, `output/`, `uv.lock` за бажанням).
2. Перейменувати `src/lab1` → `src/labN`, оновити `name` і `packages` у `pyproject.toml`,
   а також `MODULE` у `justfile`.
3. Розпакувати `docs/Lab_work_N/Lab_work_N.rar` у `lab-N/docs/samples/`,
   покласти `Lab_work_N.pdf` у `lab-N/docs/task/`.
4. Створити `lab-N/docs/report/report.md` за структурою з розділу V завдання.

Решта — конфіг ruff, `[tool.pyright]`, `.gitignore`, задачі Zed — уже в шаблоні
й працює для будь-якої лаби без правок.

## Вимоги до звіту

Структура (розділ V завдання ЛР): титульний аркуш → мета і завдання → результати
(синтезована математична модель, архітектурне проектування та його опис, опис структури
проєкту, результати роботи програми, програмний код) → висновки → підписи.

Оформлення за ДСТУ 3008:2015: А4, Times New Roman 12 pt, інтервал 1.0,
поля — зверху 2 см, знизу 2 см, справа 2 см, зліва 2.5 см, абзац 1.25 см.

## Корисне

- У системі **немає poppler**, тому вбудоване читання PDF падає. Текст із завдань
  дістається так:
  ```sh
  uv run --quiet --with pypdf python -c "
  from pypdf import PdfReader
  r = PdfReader('lab-1/docs/task/lab-1.pdf')
  print('\n'.join(p.extract_text() for p in r.pages))
  "
  ```
- Реальні дані (`Oschadbank (USD).xls`, `Data_Set_*.xlsx`) читаємо просто з `docs/`
  через `labN/paths.py` — не копіюємо бінарники в `project/`.
- Приклади викладача (`lab-1/docs/samples/*.py`) написані в процедурному стилі під
  старі версії numpy/pandas. Використовуємо їх як референс алгоритмів, а не як взірець
  стилю: наш код — типізований, розбитий на модулі, без `np.random.*` глобального стану
  (беремо `np.random.default_rng(seed)`).
