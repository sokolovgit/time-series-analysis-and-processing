# МКР, завдання 8. Модель і прогноз часового ряду методом найменших квадратів

Соколов Олександр, ІП-33. Річні світові викиди CO₂ за 1970–2024 роки (worldometers.info):
вибір моделі тренду за МНК за точністю прогнозу поза вибіркою, МНК-модель AR(1) для
залишків, доведення ефективності ретроспективним прогнозом і тестом Дібольда–Маріано,
прогноз на 2025–2034 роки з інтервалами.

Залежностями керує [uv](https://docs.astral.sh/uv/). Запуск:

```sh
cd project
uv run python src/main.py              # усі етапи з кешу data/co2.csv, кілька секунд
uv run python src/main.py --refresh    # заново отримати дані з сайту
```

Програма друкує результати всіх етапів і зберігає графіки в `project/out/`.

## Структура

```
project/data/co2.csv       кеш отриманих з сайту даних
project/src/main.py        точка входу, сім етапів
project/src/loaders.py     скрапінг worldometers, кеш
project/src/lsm.py         МНК, моделі тренду, AR(1), інтервали прогнозу
project/src/evaluate.py    метрики, бектест, базові прогнози, тести залишків, Дібольд–Маріано
project/src/plots.py       графіки
```
